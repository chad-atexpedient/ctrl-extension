What it does

Everything a side-panel chat should have done from the start.

CTRL isn't a wrapper around a chat API. It's a full agent runtime with its own tools, memory, and a browser it can actually operate.

Context-aware chat

Pull in the current page or a text selection so you're never explaining what you're looking at. Streaming responses, with a graceful fallback for providers that don't stream.

Browser agent

11 CDP-driven tools — navigate, click, type, screenshot, extract text, enumerate elements, even run raw JavaScript. Anything that changes something needs your OK, and it fails closed: no response in 60 seconds, or the panel's closed, and it's denied automatically.

20+ built-in skills

Code interpreter, Excel/CSV/JSON tools, slide decks and documents, chart building, a regex tester, a web scraper, 3D scenes, color palettes, PDF export, and more — callable straight from chat.

MCP client

Connect Model Context Protocol servers for still more tools and data sources, without waiting on a native integration to be built for you.

Snippets, commands & memory

/summarize, /slides, /mvp, voice dictation, and searchable, taggable, pinnable conversation history with export/import.

Encrypted & sandboxed

API keys encrypted with AES-256-GCM before they touch disk. AI-generated previews render in a network-isolated sandbox. No analytics, ever.

Spend, tracked automatically

Every call's token usage and cost, broken down by provider and model. Session, week, and month totals, a 14-day chart, and CSV export — no spreadsheet required.

Keyboard-first

Ctrl+K command palette, Ctrl+J code pane, Ctrl+Shift+S sidebar, Alt+Shift+A/B to open the panel or toggle the agent — every surface reachable without a mouse.

Least privilege by default

Custom and local providers get a permission request scoped to that one origin, not blanket access. Every tool call is rate-limited, and a rolling audit log tracks what the extension actually did.

Get started

Install from source in under a minute.

CTRL isn't on a store yet — loading it unpacked is the fastest way to try it.

Clone or download the repo

git clone https://github.com/chad-atexpedient/ctrl-extension.git

Open your browser's extensions page

chrome://extensions in Chrome or Edge — see the repo's DISTRIBUTION.md for Firefox and Safari.

Enable Developer mode, then Load unpacked

Select the project folder you cloned.

Open the side panel and add a key

Click the toolbar icon or press Alt+Shift+A, then connect the provider you use.
