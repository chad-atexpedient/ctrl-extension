What it does

Everything a side-panel chat should have done from the start.

CTRL isn't a wrapper around a chat API. It's a full agent runtime with its own tools, memory, and a browser it can actually operate.

Context-aware chat

Pull in the current page or a text selection so you're never explaining what you're looking at. Streaming responses, with a graceful fallback for providers that don't stream.

Browser agent

A Chrome DevTools Protocol–driven agent that navigates, clicks, types, screenshots, and fills forms — with an explicit approval step before anything that could change something.

20+ built-in skills

Code interpreter, Excel/CSV/JSON tools, slide decks and documents, chart building, a regex tester, web scraper, git automation, PDF tools, and more — callable straight from chat.

MCP client

Connect Model Context Protocol servers for still more tools and data sources, without waiting on a native integration to be built for you.

Snippets, commands & memory

/summarize, /slides, /mvp, a full command palette (Ctrl+K), and searchable, taggable, pinnable conversation history with export/import.

Encrypted & sandboxed

API keys encrypted with AES-256-GCM before they touch disk. AI-generated previews render in a network-isolated sandbox. No analytics, ever.

Get started

Install from source in under a minute.

CTRL isn't on a store yet — loading it unpacked is the fastest way to try it.

Clone or download the repo

git clone https://github.com/chad-atexpedient/ctrl-extension.git

Open your browser's extensions page

chrome://extensions in Chrome or Edge — see the repo's DISTRIBUTION.md for Firefox and Safari.

Enable Developer mode, then Load unpacked

Select the project folder you cloned.

Open the side panel and add a key

Click the toolbar icon or press Alt+Shift+A, then connect the provider you use.
