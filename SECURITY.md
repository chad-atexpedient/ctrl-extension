# Security Policy

## Supported versions

Security fixes are applied to the latest tagged release and the default branch.

## Reporting a vulnerability

Please do not disclose credentials, API keys, or exploitable details in a
public issue. Use GitHub's private Security Advisory workflow for this
repository when available. If private advisories are unavailable, open an issue
with the title `SECURITY CONTACT NEEDED` and do not include reproduction details;
maintainers will provide a private channel.

Include the affected version, browser, reproduction steps, impact, and a safe
minimal proof of concept. We will acknowledge reports as soon as practical and
coordinate disclosure after a fix is available.

## Credential handling

Never attach API keys, provider tokens, private extension signing keys, or
personal browsing data to an issue, pull request, log, screenshot, or test
fixture.
