# Code of Conduct

## Our standard

We want CTRL Extension to be a welcoming, respectful, and technically rigorous
project. Participants are expected to communicate professionally, assume good
intent, accept constructive feedback, and focus criticism on ideas and code
rather than people.

Unacceptable behavior includes harassment, discrimination, threats, doxxing,
sexualized conduct, deliberate disruption, and publishing private information.

## Enforcement

Project maintainers may remove content, close discussions, or restrict
participation when this code is violated. Report concerns privately through the
security/contact process rather than escalating in public threads.
