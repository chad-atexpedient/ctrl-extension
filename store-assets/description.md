# CTRL Extension

CTRL is an in-browser AI workspace that keeps your conversations next to the
page you are working on. Connect supported AI providers with your own API key,
choose enabled models, and use the side panel for context-aware chat without
leaving the browser.

## Highlights

- Context-aware chat with optional page and selection context
- Streaming responses with a graceful fallback for non-streaming providers
- Provider catalog for OpenAI, Anthropic, Google, DeepSeek, Mistral, Groq,
  OpenRouter, Z.ai, MiniMax, Alibaba, Meta, and compatible custom endpoints
- Reusable prompt snippets with slash autocomplete
- Conversation search, date filters, tags, pinning, export, and import
- Browser Agent for supported Chromium builds with explicit action approval
- Code output drawer, terminal, preview, and export workflows
- Spending estimates and token usage visibility
- Local encrypted credential storage and no analytics tracking
- Themes, density settings, keyboard shortcuts, accessibility semantics, and
  reduced-motion support

CTRL does not provide an AI service or API keys. You connect your own provider
credentials and pay providers directly according to their terms.
