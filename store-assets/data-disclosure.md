# Data Use Disclosure

- CTRL does not operate a telemetry, analytics, advertising, or profiling
  backend.
- API keys, settings, snippets, conversation history, and spending records are
  stored locally in browser extension storage.
- Prompt text, optional page context, and attachments are sent directly to the
  provider endpoint selected by the user.
- Custom MCP endpoints and Browser Agent relay servers are user-configured and
  may receive data explicitly included in a tool request.
- Users can clear local history, credentials, snippets, and spending records
  from the options page.
- The extension does not sell user data or use it for credit, employment,
  insurance, or advertising decisions.
